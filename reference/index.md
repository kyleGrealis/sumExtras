# Package index

## Core Table Styling

Main functions for adding professional formatting to gtsummary tables

- [`extras()`](https://kyleGrealis.com/sumExtras/reference/extras.md) :
  Add standard styling and formatting to gtsummary tables
- [`clean_table()`](https://kyleGrealis.com/sumExtras/reference/clean_table.md)
  : Standardize missing value display across all gtsummary table types

## Automatic Variable Labeling

Functions for managing variable labels from data dictionaries

- [`add_auto_labels()`](https://kyleGrealis.com/sumExtras/reference/add_auto_labels.md)
  : Add automatic labels from dictionary to a gtsummary table
- [`apply_labels_from_dictionary()`](https://kyleGrealis.com/sumExtras/reference/apply_labels_from_dictionary.md)
  : Apply variable labels from dictionary to data as attributes

## Theme Functions

Apply JAMA-style compact themes for consistent professional formatting

- [`use_jama_theme()`](https://kyleGrealis.com/sumExtras/reference/use_jama_theme.md)
  : Apply JAMA Compact Theme to gtsummary Tables
- [`theme_gt_compact()`](https://kyleGrealis.com/sumExtras/reference/theme_gt_compact.md)
  : Apply compact JAMA-style theme to gt tables

## Group Header Styling

Enhanced formatting for variable group headers in summary tables

- [`add_group_styling()`](https://kyleGrealis.com/sumExtras/reference/add_group_styling.md)
  : Apply styling to variable group headers in gtsummary tables
- [`add_group_colors()`](https://kyleGrealis.com/sumExtras/reference/add_group_colors.md)
  : Add background colors to group headers with automatic gt conversion
- [`get_group_rows()`](https://kyleGrealis.com/sumExtras/reference/get_group_rows.md)
  : Get row numbers of variable group headers for gt styling
